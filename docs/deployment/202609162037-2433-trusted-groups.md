真实组场景使用短 TTL 30 秒：同租户另一合法 client 可取得同一快照；已有会话保持原期限；移除成员后的新认证不再取得旧组；严格到期后两个旧 session 的身份仍有效但可信组不可访问；重新认证恢复事实；cookie refresh 不延寿；provider 配置变化和停用/再启用使旧身份拒绝。真实 Keycloak 暂停导致新认证失败，恢复后重新认证成功。Hydra/PG 失败沿既有验证场景拒绝整次认证。

Keycloak 26.7.3 的 GroupMembershipMapper 使用 `full.path=true`。该 mapper 零成员时省略 claim（OIDCAttributeMapperHelper 对空集合返回 null）；因此真实 T2 的移除组结果为 `unavailable/claim_missing`。已验签真实空数组的 `available([])` 语义由 adapter、核心及 PG 用例覆盖，不把省略 claim 伪称为空数组。

首次 PG 扩展把额外事务测试内联进既有大型 async 测试，触发测试线程栈溢出；已拆成独立 canonical 用例并通过。首次下游执行暴露了 fixture client 验证 secret 重复和上述 Keycloak 省略行为，已修正测试输入/断言后完整重跑通过。最终 CI 还发现跨主体来源测试在尝试污染记录时先被现有复合外键拒绝；已改为断言 SQLSTATE 23503，并确认原会话保持有效，无运行时改动。

## 独立消费复现

从上述固定 revision 的 `tests/consumer` 复制源码到仓外可再生目录。将唯一 Identity 依赖替换为：

```toml
rss-identity-client = { git = "https://dev.azure.com/shengming0923/rss/_git/rss-identity", rev = "f96ecbc7d1c0106c6d34687738d2feb23a681d4a" }
```

从该 revision 的 `tests/consumer/Cargo.lock` 开始，只给 `rss-identity-client` 和 `rss-identity-contracts` 两个 package 增加同一 source 行，其他解析保持原样：

```toml
source = "git+https://dev.azure.com/shengming0923/rss/_git/rss-identity?rev=f96ecbc7d1c0106c6d34687738d2feb23a681d4a#f96ecbc7d1c0106c6d34687738d2feb23a681d4a"
```

实际使用 `CARGO_NET_GIT_FETCH_WITH_CLI=true` 通过系统 Git credential helper 获取私有 Git，未在 manifest/lock 里加入凭据。独立 consumer 的 Cargo 命令从 `/tmp` 执行，避开工作仓祖先 `.cargo/config.toml`；`/tmp/.cargo`、`/.cargo` 及 Cargo home 无配置，显式 target 指向该 consumer 的私有目录，无 patch/source replacement。

```sh
cd /tmp
CARGO_NET_GIT_FETCH_WITH_CLI=true CARGO_TARGET_DIR="$SDK_ROOT/target"   cargo test --locked --manifest-path "$SDK_ROOT/Cargo.toml" --no-run
CARGO_NET_GIT_FETCH_WITH_CLI=true CARGO_TARGET_DIR="$SDK_ROOT/target"   cargo metadata --locked --manifest-path "$SDK_ROOT/Cargo.toml" --format-version=1
```

实际行为沿用固定源码 `hack/downstream.py` 建立真实 PG/Keycloak/Hydra 和 Axum fixture。在 PATH 中放置临时 `python3` shim，仅拦截 `hack/consumer.py` 调用，将执行替换为上述独立 manifest 的 `cargo test --locked -- --ignored --test-threads=1`；其它 Python 调用转交绝对系统解释器。完整 shim 如下（首行替换为本机绝对 Python 3.11+ 路径，SDK_ROOT 为独立目录）：

```python
#!/opt/homebrew/bin/python3
import os, sys, subprocess, json, time
from pathlib import Path
if len(sys.argv) > 1 and sys.argv[1].endswith('/hack/consumer.py'):
    root = Path(os.environ['SDK_ROOT'])
    env = {**os.environ, 'CARGO_TARGET_DIR': str(root / 'target'),
           'CARGO_NET_GIT_FETCH_WITH_CLI': 'true'}
    result = subprocess.run(
        ['cargo', 'test', '--locked', '--manifest-path', str(root / 'Cargo.toml'),
         '--', '--ignored', '--test-threads=1'], cwd='/tmp', env=env,
        capture_output=True, text=True, timeout=180)
    passed = result.returncode == 0 and (
        'test result: ok. 1 passed; 0 failed; 0 ignored;' in result.stdout)
    with (root / 'behavior.jsonl').open('a') as log:
        log.write(json.dumps({'passed': passed,
            'scenario': env.get('IDENTITY_TEST_GROUP_STATUS', 'local_identity_logout'),
            'timestamp': int(time.time())}) + '\n')
    print('fixed Git SDK consumer: ' + ('passed' if passed else 'failed'))
    sys.exit(0 if passed else 1)
os.execv('/opt/homebrew/bin/python3', ['/opt/homebrew/bin/python3', *sys.argv[1:]])
```

先编译独立 consumer，避免消耗短 TTL；然后从 Identity checkout 执行 `PATH="$SHIM_DIR:$PATH" /absolute/python3 hack/downstream.py`。fixture 原有 env 将凭证只传给测试进程；shim 仅记录场景/时间/布尔结果，原始输出留在内存，不打印凭证、组全集或 provider 原文。三次 consumer 调用必须分别看到真实测试 `1 passed`，不能用 no-run 或零测试代替。仓内常规 `make test-downstream` 仍使用仓内独立 consumer，不依赖此本地 shim。

可再生目录为 `rss-external-check/identity-2433/sdk-f96ecbc`；唯一源码由固定 Git revision 持有，唯一验收结论由本记录和 PR 评论持有。

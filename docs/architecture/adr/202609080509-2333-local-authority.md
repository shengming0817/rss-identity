# #2333：本地账户与独立维护身份（历史决定）

适用时期：#2435 嵌入架构之前的中央模式。由 [#2435](202609170001-2435-embedded-authentication.md) 替代，不作为当前操作说明。

## 当时的决定与取舍

本地账户变更与安全事件使用同一事务；初始化和应急恢复由独立数据库维护身份执行。#2358 用直接维护命令替代临时授权票据，避免维护第二套秘密、过期与重放状态机。恢复只替换密码并推进失效代际，不隐式启用账户或授予角色。

## 替代关系

中央管理员与系统域资格已退出；当前管理角色和防锁死由宿主提供。维护凭据隔离、确认提交后返回和未知结果不重试的理由继续适用。

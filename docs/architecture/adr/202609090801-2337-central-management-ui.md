# #2337：单一管理 UI（历史决定）

适用时期：#2435 嵌入架构之前的中央模式。由 [#2435](202609170001-2435-embedded-authentication.md) 替代，不作为当前操作说明。

## 当时的决定与取舍

中央模式将日常管理统一到 session 认证的 HTTP/UI，删除旁路管理 CLI，避免两套权限判定。后端持有授权与事务，Web 持有页面；维护命令只处理初始化和应急恢复。

## 替代关系

中央管理角色和路由退出；当前组件在事务内调用宿主策略，Web 与参考宿主按当前 HTTP 接口组合。

历史实现与当时的验证记录通过 [#2337 工作项](https://dev.azure.com/shengming0923/rss/_workitems/edit/2337) 和本文件 Git 历史追溯。历史结果不表示当前版本已验证；来源与许可证见[来源索引](../../reference/sources.md)。

# #2334：中央登录会话（历史决定）

适用时期：#2435 嵌入架构之前的中央模式。由 [#2435](202609170001-2435-embedded-authentication.md) 替代，不作为当前操作说明。

## 当时的决定与取舍

采用单一账户认证代际和服务端不透明会话，避免另建 refresh family/history 或重复状态。刷新原子旋转凭据、保留认证时间与绝对期限；并发失败方不能撤销胜出凭据。每次权威读取重验撤销，不缓存成功身份。

## 替代关系

中央角色决定会话策略的模式已退出；当前策略由宿主显式传入，并保留会话原期限。HTTP 和可信身份边界以当前嵌入接口为准。

历史实现与当时的验证记录通过 [#2334 工作项](https://dev.azure.com/shengming0923/rss/_workitems/edit/2334) 和本文件 Git 历史追溯。历史结果不表示当前版本已验证；来源与许可证见[来源索引](../../reference/sources.md)。

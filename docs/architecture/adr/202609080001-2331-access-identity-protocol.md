# #2331：身份、租户与产品会话协议（历史决定）

适用时期：#2435 嵌入架构之前的中央模式。由 [#2435](202609170001-2435-embedded-authentication.md) 替代，不作为当前操作说明。

## 当时的决定与取舍

中央架构选择自有账户、成员与会话，将标准 OIDC 服务端协议委托给 Hydra，而不是自建完整 OP 或把账户 owner 转移给另一套 IAM。代价是额外服务与跨服务不确定结果；当时用在线权威复核限制旧协议凭据的权限。

## 替代关系

嵌入模式消除了中央下游协议和 Hydra 依赖，身份与会话在宿主实例内验证，资源授权仍归消费产品。

历史实现与当时的验证记录通过 [#2331 工作项](https://dev.azure.com/shengming0923/rss/_workitems/edit/2331) 和本文件 Git 历史追溯。历史结果不表示当前版本已验证；来源与许可证见[来源索引](../../reference/sources.md)。

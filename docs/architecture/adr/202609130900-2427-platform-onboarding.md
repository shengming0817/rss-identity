# #2427：平台开通与受认证 CLI（历史决定）

适用时期：#2435 嵌入架构之前的中央模式。由 [#2435](202609170001-2435-embedded-authentication.md) 替代，不作为当前操作说明。

## 当时的决定与取舍

中央模式曾区分系统域与业务租户，以显式平台角色开通租户；CLI 通过服务端会话认证，防止把一次性维护身份扩展为日常超级权限。这增加了跨域保护、角色和动态租户绑定责任。

## 替代关系

嵌入模式把租户准入、管理角色和资源授权归还宿主，删除中央平台与 SSO CLI。宿主配置租户不等于接纳通用 IAM 或 MDM MSP。

历史实现与当时的验证记录通过 [#2427 工作项](https://dev.azure.com/shengming0923/rss/_workitems/edit/2427) 和本文件 Git 历史追溯。历史结果不表示当前版本已验证；来源与许可证见[来源索引](../../reference/sources.md)。
